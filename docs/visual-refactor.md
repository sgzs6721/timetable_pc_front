# PC Web 全站视觉重构验收

## 设计基线

- 主色沿用小程序蓝色语义，并调整为适合桌面端长时间操作的靛蓝体系；成功、警告、错误、经营图表使用统一的语义色。
- 正文字号提升至 13px，页面标题、卡片标题、表头、说明文字建立稳定层级，减少原有界面过密和难读的问题。
- 卡片、表格、筛选栏、弹窗、抽屉、下拉框、日期控件和分页统一圆角、边框、阴影、间距与焦点态。
- 侧栏、页面标题、登录页和刷新操作统一使用 Ant Design 线性图标；业务 SVG 图标同步更新到新品牌色。
- 悬浮、选中、拖动目标、输入焦点和页面进入使用短时缓动；系统开启“减少动态效果”时自动停用动画。

## 样式结构

- `src/styles/global.css`：设计令牌、基础排版、滚动条、可访问焦点和动态效果策略。
- `src/styles/design.css`：Ant Design 控件、表格、弹窗、抽屉、页签和状态反馈。
- `src/styles/work-base.css`：页面标题、业务卡片、工具栏、指标、空状态和快捷入口。
- `src/layouts/AppShell.css`：全局侧栏、顶栏、机构/校区切换和账户区域。
- `src/styles/work-students.css`：学员、卡片、缴费和打卡专用交互。
- `src/styles/work-schedule-*.css`：课表网格、课程块、拖放和编辑面板。
- `src/styles/work-finance.css`：收支、工资、缴费和经营分析图表。
- 页面独立样式：登录、首页、法律文本和营销中心。

## 验证门槛

- `npm run build` 必须通过 TypeScript 与 Vite 生产构建。
- `npm run check:source-size` 保证 TypeScript、TSX 和 CSS 单文件不超过 800 行。
- 登录页、法律页、已登录工作台、课表、经营指标和营销卡片均完成浏览器渲染复核。
- 所有临时视觉验收页面均在复核后删除，不进入交付代码。
